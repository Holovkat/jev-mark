Agent logic lab · spatial navigation

          
Radioactive Run

          
Generate & run builds a seeded field locally (same seed and width, same field every time) and then sends the token on its way. The JEV model makes every navigation decision whenever more than one legal move exists, including when to go back; the code only enforces legality, applies a forced move when exactly one legal move exists, and keeps score of the metrics. The model sees a fog-of-war map of the cells it has observed plus its recent move history, and an optional memory aid summarises what it has already observed (dead-end and explored-pocket flags derived only from seen cells) at a level recorded per run. Parallel races start several independent tokens on the same field at once; their decision requests run concurrently, and each token is recorded as its own run. "Follow mapped route" guides a new run with the recorded path and observations of the field's latest completed run — the first completed run scouts the course, later runs (for example a different model) navigate against that predetermined route, and route adherence is recorded per run. A run ends at the exit, at the move budget (4× the shortest path, at least +40), when you press Stop, or after three failed attempts at one decision.
