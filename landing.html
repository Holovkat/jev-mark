01 / BENCHMARK

Benchmark suites,
measured results.

The harness in this repo doesn't ask models to chat — it asks them to commit to bounded answers and scores them exactly. Eleven logic baselines. A 100-question quiz that separates definite answers from judgment calls, and counts over-caution ("it can't be determined") as its own failure mode. Ambiguity and common-sense reasoning suites. And a judge that ranks raw agent responses through five shuffled orderings, because a single ranking pass is position-biased.

02 / WATERMARK

TypeSafe is the watermark —
the reference for every local provider.

Hosted TypeSafe jev-latest sets the reference mark for logical testing: the same bounded questions, the same request contract, one stable gateway. Every local provider — Ollama-backed JEV hybrids, the contrastive CLM, Apple's on-device Foundation Models — answers the identical suites, and the watermark's answers set the bar. No provider silently falls back to another; failures are explicit.

03 / SPEED

Prefill once. Score everything.
Assemble the JSON in code.

Arbitrary JSON generation is removed from the answer path — that's where the speed and the reliability come from. The first live decision against gemma4:12b, cold, measured 1.07 s total: the context is prefilled once and shared, scoring all fields against it is the cheap part, and the output object is built deterministically. Warm decisions run at roughly half a second.

Request anatomy — first live decisiongemma4:12b · cold
POST /v1/decision            ← one request, many fields
schema:
  route   choice[ local · cloud · queue ]
  risk    score[ 1..5 ]
  block   noul
contexts: [ …one evidence packet… ]

prefill   937 ms   (once, shared by every field)
scoring   132 ms   (all fields, in parallel)
json        0 ms   (assembled in code — never generated)
CHOICE
Pick one label from a finite set. Classification, routing, triage, extraction into bounded labels.
SCORE
Bounded 2–10 ordered levels, with the exact tree distribution converted into a probability-weighted score.
NOUL
Yes / no with its probability retained. Policy checks and gates.

Three primitives cover the bounded-decision space. Related decisions over one evidence packet travel together — up to 32 fields per batch, every answer carrying its distribution, so downstream code can gate on confidence instead of parsing prose.

04 / RUN

Real-time decisions:
the Radioactive Run.

A hazardous grid. A model with fog of war and nothing but the history it accumulates, one decision request per step. The board is generated from a seed — same seed, same board, so models are compared on equal ground — and a protected route always exists. The code is only the referee: it enforces legality and records metrics, and it never chooses between two legal moves. When only one move is legal, it's applied automatically and labelled forced — that's physics, not strategy.

The comparison table records moves over the breadth-first shortest path, revisits, dead ends and pocket cells, flagged moves chosen anyway (seen vs unseen), invalid responses, retries, and average decision time and confidence per run. Colour tells the story on the board and in the prompt alike: green is safe to reuse, yellow is a known dead end, red means been-here-and-done-that.

05 / AIR-GAP OPERATION

The same decision engine, run without the internet.

The engine loads GGUF blobs directly from local disk. CLM runs as two local processes. Apple Foundation Models runs on-device. Only the TypeSafe watermark touches the network — and it's optional. A single Mac and a menu-bar service expose one gateway on the LAN, so trusted devices on the floor share the same decision engine. If the network disappears, the decisions don't.

Bounded, low-latency decisions with distributions are what machinery control needs; free-text generation is a poor fit for it. The applications below are the intended targets for this engine — candidate use cases, not yet demonstrated results.

warehouse racking stack sequencing robotic movement routing & triage policy checks bounded extraction
JEV · llama.cpploads GGUF directly from the Ollama store — no API, no cloud
CLM v0.1-8Bfrozen encoder + local heads, two processes on loopback
Apple FMon-device guided generation, loopback adapter only
LAN gatewayone stable endpoint for every trusted device on the floor
TypeSafethe only uplink — used as the watermark, never required

Every decision provider binds to loopback; the LAN gateway is the only network listener. The TypeSafe watermark is the only uplink — and it is optional.

06 / THE APP

The workbench is the app —
the same suites, in the browser.

The browser workbench talks to the same gateway, through the same selected provider the agents use. Pick a case from the logic baselines, the ambiguity or reasoning sets, or the Parallel & agentic suite — edit its question or evidence, run it, and read the returned fields, probabilities, reference comparison, latency, and raw response. The 100-question quiz, the Radioactive Run boards, and the parallel report (saved runs, side by side, per provider) live in the same page. Provider selection happens in the macOS menu-bar service.
